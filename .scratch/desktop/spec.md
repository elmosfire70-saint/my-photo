# WPF 읽기 전용 폴더 보기

전체 계획은 ../../plan.md를 따른다. 기존 수집기를 연결하는 첫 데스크톱 화면이다.

- 사용자가 폴더를 선택한 뒤에만 읽기 전용 수집한다. UI 검사에는 합성 자료만 쓴다.
- 수집은 UI 스레드 밖에서 수행하며 완료 전에 커밋된 목록을 갱신한다. 취소와 수집 중 닫기는 저장을 마친 뒤 종료한다.
- 선택한 폴더의 목록만 표시하고 날짜 범위 및 200건 이전/다음 페이지를 제공한다.
- 원본 태그와 날짜 출처, 미검증/손상 상태를 표시한다. 원본 쓰기/삭제 기능은 없다.
- 검증된 정상 항목만 첫 프레임 미리보기를 생성한다. 긴 변 2400px, 입력 5천만 픽셀 한도와 축소 여부를 알린다.
- 미리보기 기준 10~800% 확대, 화면 맞춤, 가로/세로 스크롤과 드래그 이동을 제공한다. 선택이 바뀌면 오래된 비동기 결과를 표시하지 않는다.
- 합성 UI 검사로 날짜 필터, 미리보기 로딩, 확대 후 양방향 스크롤, 오류 표시, 원본 해시 불변을 확인하고 화면을 저장한다.
