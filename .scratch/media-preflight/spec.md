# 미디어 도구 사전 검증

전체 기능은 ../../plan.md를 따른다. 이번 범위는 사용자가 확인한 두 경계다.

1. 생성한 시험 파일에서 미리보기와 메타데이터를 읽는다.
2. JPEG 시험 복사본의 백업→쓰기→재읽기→복원을 검증한다.

Magick.NET Q8 x64 15.0.0과 공식 ExifTool Windows 13.60을 후보로 검증한다. 원본 사용자 파일·XnView 파일은 사용하지 않는다. 결과는 test-artifacts에만 보관한다. 합성 포맷 왕복 검증은 실제 카메라 RAW·아이폰·영상 샘플 검증을 대체하지 않는다. 해당 항목은 미검증으로 남긴다. 비교 기준은 178a853이다.

## 관찰된 제약

ExifTool 배포 URL이 HTML을 반환해 확보하지 못했다. 이번 두 경계 시험은 Magick.NET에 한정한다. JPEG 재인코딩 쓰기는 시험 전용이며 실제 원본 수정 기능으로 재사용하지 않는다. ExifTool·HEIC·실물 RAW/영상·배포 조건 검증은 다음 작업으로 남긴다.
