# 연도·월 타임라인

전체 계획은 ../../plan.md를 따른다.

- 선택 폴더의 모든 DB 항목을 월별로 집계하고 전체/연도/월 항목 수와 추정 UTC·오류 수를 구분한다. 현재 목록 페이지나 기간 조건이 집계 전체를 제한하지 않는다.
- 연도나 월을 선택하면 해당 달력 기간 양끝을 포함해 날짜 입력과 목록이 함께 갱신되고 첫 페이지로 돌아간다. 윤년과 12월을 올바르게 처리한다.
- 전체 날짜로 복귀하거나 직접 기간을 지정할 수 있다. 다른 폴더/DB 선택 시 이전 트리 상태를 재사용하지 않는다.
- 수집 완료/취소 후 집계를 갱신한다. 사진·영상 원본이나 DB 스키마를 수정하지 않는다.
- 합성 자료로 루트 격리·전체 집계·날짜 출처·빈 목록·페이지 초기화와 실제 WPF 선택 경로를 검증한다.

대규모 성능/키셋 페이지·지도·사용자 보정·실제 아이폰/GPU/HDR 검증은 이번 작업이 아니다.
