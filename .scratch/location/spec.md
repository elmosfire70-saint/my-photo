# 경계 후보 검증과 원본 GPS 표시

전체 계획은 ../../plan.md를 따른다.

- 출처 조사 문서에 API 표기와 실제 경계 파일 개수·시점·한글/코드·라이선스의 차이를 기록한다. 검증되지 않은 경계나 이름을 앱에 채택하지 않는다.
- 저장된 원본 EXIF JSON에서 GPSLatitude/GPSLongitude의 3개 유리수와 N/S/E/W 방향을 읽어 십진 좌표로 변환한다. 방향을 임의로 추측하지 않는다.
- 좌표 없음, 부분 누락, 형식/분모/범위 오류를 구분한다. 0도, 남위/서경, 극점/날짜변경선의 유효한 값도 처리한다.
- 사진 메타데이터 화면에 원본 GPS 또는 미확정 사유를 표시한다. 영상은 GPS 미추출로 표시한다.
- 파서는 파일·DB·네트워크에 접근하지 않으며 원본 태그와 파일을 바꾸지 않는다. 합성 EXIF와 기존 수집/UI 검사를 통과한다.

자동 한글 지역 분류·지도·위치 검색·추정 좌표·실물 GPS 정확성 검증은 이번 작업 완료 기준이 아니다.
