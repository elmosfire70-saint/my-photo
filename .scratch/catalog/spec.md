# 읽기 전용 사진 목록 수집

전체 계획은 ../../plan.md를 따른다. 새 명령행 모듈은 명시한 폴더만 읽는다. DB는 원본 폴더 밖에 두고 원본 파일은 생성/수정/삭제하지 않는다.

- 검증된 일반 이미지의 헤더와 EXIF·프로필을 읽어 상대 경로, 크기, 수정시각, 이미지 크기, 촬영일/시간대 출처와 함께 SQLite에 저장한다.
- 미검증 HEIC/RAW/영상과 손상 파일은 개별 오류로 기록하고 다음 파일을 처리한다. 링크/정션은 따라가지 않는다.
- 파일별 저장을 완료하고 취소를 반영한다. 재실행은 변하지 않은 정상 항목을 건너뛰며 중복 행을 만들지 않는다. 기존 DB 기록을 자동 삭제하지 않는다.
- 날짜 범위와 제한된 건수로 목록을 조회한다. EXIF 날짜가 없거나 잘못된 경우 파일 수정 UTC 시각으로 대체하고 추정 출처를 표시한다.
- 재분석할 때 원본 태그/프로필만 저장한다. 사용자 보정 기능은 아직 없고 원본 파일에 적용하지 않는다.
- 합성 파일만으로 중단/재개·날짜 범위·손상/미검증 격리·메타데이터 보존과 원본 해시 불변을 확인한다.

이번 범위는 GUI, 전체 ExifTool 태그 통합, 미리보기 캐시, 드라이브 문자 변경 대응, 일일 백업, 100만 건 성능을 포함하지 않는다. 크기/수정시각이 같은 내용 변경은 이번 증분 검사로 감지하지 못한다. 메타데이터 읽기는 전체 픽셀 디코딩 검증이 아니다.
