# 아이폰 HEIC 사진과 MOV/MP4 재생

전체 계획은 ../../plan.md를 따른다. 최신 안정 공개 배포를 확인하고 버전/해시/출처를 기록한다.

- 기존 디코더로 실제 HEIC/HEIF 파일의 미리보기를 열고 원본을 수정하지 않는다.
- 로컬 MOV/MP4를 앱 내부 VLC 엔진으로 재생한다. 재생/일시정지/정지, 위치 탐색, 볼륨과 오류 표시를 제공한다.
- 사진/영상 전환 및 창 종료 시 이전 영상·오디오를 중단하고 자원을 정리한다. 자동 재생은 하지 않고 사용자가 재생을 누른다.
- 영상은 원본을 재인코딩하거나 외부로 전송하지 않는다. URL을 받아 재생하지 않는다. 시스템 코덱이나 보안 설정을 바꾸지 않는다.
- DB에서 HEIC/영상 미검증 상태를 다시 수집하면 갱신한다. 영상 날짜/GPS 미추출과 HDR/Dolby Vision 검증 한계를 표시한다.
- 공개/합성 시험 파일로 HEIC 디코딩과 H.264/HEVC 영상 재생 경계를 검증하고 기존 검사도 다시 실행한다. 파일·런타임·개인정보는 Git에 올리지 않는다.

실제 사용자 아이폰 자료, Live Photo 연결, 모든 HDR 색 정확성, 전체 영상 메타데이터·설치본 배포는 이번 완료 기준에 포함하지 않는다.
