# 연도·월 타임라인

개발 버전의 선택 폴더별 연월 탐색 기능이다. 새 패키지나 DB 스키마 변경 없이 SQLite 집계와 기본 WPF TreeView를 사용한다.

## 사용

앱을 닫고 기존 바탕화면의 내 사진함 실행.cmd로 다시 실행한다. 폴더 선택/다시 수집을 마치면 왼쪽에 연도·월이 나타난다. 수집을 취소해도 그때까지 DB에 저장된 항목을 집계한다.

- 연도를 누르면 해당 연도의 1월 1일부터 12월 31일, 펼친 월을 누르면 그 달의 첫날부터 마지막 날을 표시한다. 날짜 입력도 함께 바뀌고 첫 페이지로 돌아간다.
- 전체 날짜로 복귀하거나 직접 시작일/종료일을 입력할 수 있다. 직접 기간을 적용하면 트리의 선택을 해제해 별도 조건임을 알린다.
- 전체/연도/월 수는 현재 200건 페이지나 기간 필터가 아닌 **선택 폴더 전체의 DB 항목** 기준이다. 미검증/오류도 포함하며 별도 수로 구분한다. 물리적 파일의 실시간 존재 여부나 중복 없는 실제 사진 장수라는 뜻은 아니다.
- 위 요약과 월 항목은 추정 날짜 수를 표시한다. 연도·월의 툴팁에는 오류/미검증 수를 표시한다. 영상 촬영일/GPS 미추출 항목은 파일 수정 UTC의 추정 날짜로 포함된다.
- 추정 수와 오류 수는 서로 독립적인 속성이어서 같은 항목이 두 수에 함께 포함될 수 있다.
- EXIF 촬영 달력 시각과 파일 수정 UTC는 출처를 유지한다. 촬영 시각의 시간대를 임의로 UTC로 바꾸지 않으며 서로 동일한 UTC 축으로 정규화한 통계가 아니다.
- 수집 중 목록은 계속 갱신하지만 폴더 전체 집계는 완료/취소 후 갱신한다. 폴더나 DB를 바꾸면 이전 트리 상태를 지운다. 목록 공간이 좁으면 타임라인을 접을 수 있다.

## 검증

저장소 루트에서 실행한다. 출력은 새 test-artifacts 하위 폴더여야 한다.

```powershell
E:/tools/dotnet10/dotnet.exe build src/PhotoLibrary.Desktop -c Release --no-restore
E:/tools/dotnet10/dotnet.exe run --project src/PhotoLibrary.Index -c Release --no-restore -- --self-test test-artifacts/timeline-catalog-final
E:/tools/dotnet10/dotnet.exe src/PhotoLibrary.Desktop/bin/Release/net10.0-windows/PhotoLibrary.Desktop.dll --smoke-test test-artifacts/timeline-ui-final
```

미구현 집계 검사가 실패한 뒤 구현해 위 두 검사는 exit 0으로 통과했다. 빌드는 경고 0개·오류 0개였다.

- DB 검사에서 서로 다른 루트의 5개/7개 항목을 분리하고, 월 내림차순·추정 UTC/오류 수·빈 집계·윤년 2월·12월·연도 경계를 확인했다. 집계 전후 DB 및 합성 원본의 SHA-256 불변도 확인했다.
- WPF 검사에서 합성 205개 항목의 200/5건 페이지를 만들고 2쪽에서 월 선택 시 첫 페이지/올바른 날짜로 복귀하는 것을 확인했다. 연도 선택은 2020년의 1월·2월·12월 3개 항목을 모두 포함했다.
- 전체 날짜·직접 기간·빈 기간·빈 폴더 전환, 이전 폴더 기록 보존, 기존 미리보기/800% 확대/스크롤/취소/종료 검사도 통과했다. 생성한 timeline-ui-final/window.png를 시각 확인했다.
- `--iphone-test test-artifacts/iphone-timeline-regression test-artifacts/iphone-media-final`도 exit 0이었다. 공개 HEIC와 합성 H.264/HEVC의 기존 동작은 유지됐지만 이전 단계에서 기록한 GPU 변환/종료 로그도 재현됐다. 실제 아이폰/GPU/HDR의 미검증 상태를 해제한 결과는 아니다.

## 남은 범위

집계는 선택 폴더의 저장 행을 읽으며 수집/원본 파일 수정을 하지 않는다. 삭제/오프라인 판별, 사용자 날짜 보정, 영상의 실제 촬영일/GPS, 모든 시간대 사례는 후속 범위다. 전체 SQL 집계·월 그룹 트리 생성과 OFFSET 목록은 100만 건 성능을 입증한 구현이 아니다. 대규모 인덱스/계층 가상화·실제 사용자 사진 및 마우스 입력 검증은 별도로 진행한다. 실제 아이폰 4K/HDR/GPU와 지도/행정구역 데이터도 완료로 표시하지 않는다.
