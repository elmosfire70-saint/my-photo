# my-photo

Windows PC 한 대에서 내장 디스크·외장 USB의 사진, RAW, 동영상을 기존 위치 그대로 관리하는 개인용 사진함입니다.

현재는 **계획·개발 지침만 있는 저장소**입니다. 앱 코드, 실행 파일, 지원 형식·성능의 실측 결과는 아직 없습니다.

- [구현 계획](plan.md). 기능·안전 규칙·기술 방향·검증 기준.
- [체크리스트](checklist.md). 구현 진행 상태.
- [결정 기록](context-notes.md). 인터뷰 선택과 조사 한계.
- [용어집](GLOSSARY.md). 사진함에서 사용하는 개념.

핵심은 연도·월 타임라인과 날짜·기간·한국 시도/시군구·지도 검색입니다. 원본 수정은 DB 보정 후 사용자가 별도로 적용할 때만 백업을 거쳐 수행하도록 계획합니다.

사진·영상·개인 메타데이터 DB·GPS 자료·백업·캐시는 커밋하지 않습니다. XnView 배포 파일이나 코드를 복제하지 않습니다.
